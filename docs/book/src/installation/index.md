# Installation Overview

MBL provides first-class native distribution packages across all major platforms and hardware architectures:

- **[Debian & Ubuntu (Linux)](linux.md):** Official `.deb` packages with systemd unit files, user isolation, and dynamic library support.
- **[Docker & Compose](docker.md):** Multi-arch container images (`amd64`, `arm64`) with pre-configured NVIDIA NVENC, Intel VAAPI, and Tailscale sidecar profiles.
- **[Raspberry Pi 5](raspberry-pi.md):** Native ARM64 `.deb` package and custom `pi-gen` pre-baked OS images with V4L2/DRM and Hailo NPU support.
- **[Windows & MSI Installer](windows.md):** WiX-built native 64-bit installer with background Windows Service, system tray manager, and DirectX 11 / NVENC acceleration.

Choose your target environment from the left sidebar to get started.
